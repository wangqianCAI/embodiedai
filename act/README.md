# ACT 采集、训练与推理

在已安装实验版 LeRobot 的 Windows CMD 中，从仓库根目录运行以下命令。
先修改 `act/settings.cmd`：从臂与主臂端口、各自标定 ID、相机编号、数据及模型目录。
示例端口不是设备自动检测结果。保持采集与推理的单位设置一致；历史推理使用 `use_degrees=true`，请核对自己的采集配置和标定。

```bat
act\record.cmd
act\train.cmd
act\rollout.cmd
```

三条命令分别启动采集、训练、真机运动，按所需步骤单独执行。
采集脚本中的文字已校正为透明包装耳塞入陶瓷碗；历史原命令曾错误写为 orange/box。ACT 不使用任务文字作为语言条件。
训练为 batch 4、20,000 次更新，每 2,000 步保存。推理需整个 `pretrained_model` 目录，不能只复制权重而遗漏归一化处理器。
采用原生 rollout，不叠加历史 GUI 中逐帧 ±2° 动作裁剪。60 秒是运行时间上限，30 FPS 是目标频率，并不保证所有环境都达到该速度。
